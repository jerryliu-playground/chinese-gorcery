# M15 决策记录（agent 先按默认实现，待 Jerry 确认）

spec 第 18 节里标【默认值】、[TBD] 或没写清楚的地方，按下面的做法实现。数值都在 `data/story.json`，带 `"_tbd": true`。台词草稿见 `docs/notes/M15-dialogue-drafts.md`。

## 对话系统（18.1）

- 对话数据：`data/dialogue/*.json`（主线、开场、引导、部门、贷款）和 `data/dialogue/side/*.json`（支线）；角色、引导步骤、贷款、竞争、店名设置在 `data/story.json`。每段对话：ID、样式（当面 / 电话 / 黑屏字幕）、触发条件、台词（说话人 + 表情 + 翻译键）、可选的选项和后续。全部标 `"_draft": true`。
- 每段对话最多出现一次。唯一例外是"贷款没还够"的心情台词（可重复，冷却 14 天）。
- 选项：有选项的对话必须选一个才能结束；选项可以接不同的后续对话；选了什么会存档（目前只影响后续台词）。
- 跳过：跳过当前这段以及它后面接着的对话（有选项的按第一个选项的走向算"已看过"）。开场的"跳过"一次跳完整个开场，店名保持默认。
- 对话期间时间停住，不管当前速度是多少；玩家选的速度不变，对话结束后继续。对话里的点击和回答即使在暂停时也立即生效。
- 设置里的"剧情提示"开关：只关闭支线小故事和贷款心情台词。开场、爸爸的引导电话、主线章节、新部门讲解、还清贷款的电话都照常出现（算"必要的引导"）。这个开关跟着存档走，不是全局设置。
- 角色名字：先用占位名（主角"阿明 / Ming"、爸爸、妈妈、王阿姨、留学生小李、陈师傅、阿海、周师傅），翻译键 `character.<id>.name`，待 Jerry 定名。台词里用 `{protagonist}`、`{dad}`、`{mom}`、`{shop}` 占位。
- 没有头像的角色（阿姨、留学生、三位师傅）在头像框里放大显示他们的 32×32 行走图。如果需要正式头像，请补 `portrait_<id>_<normal|happy|worried>`（需要新美术，提给 Jerry）。
- 电话样式：头像框上方右侧显示 `ui_phone` 图标并晃动（开头 0.8 秒晃得厉害），名字旁边标"通话中"。打字速度每秒 30 字。这两个是手感参数，在 `game/config/feel.tres` 可调。

## 开场（18.2）

- 开场 = 黑屏字幕 3 句 → 妈妈来电 → 父母退休（玩家二选一："好，我接！" / "我先帮你们撑一阵子"，父母回应不同）→ 给店起名 → 主角走进店里。
- 店名：最长 16 个字（中文一个字算一个），不填就用默认名"福记杂货 / Lucky Grocery"（翻译键 `story.shop.default_name`）。店名显示在顶栏下方左侧。开场以后也能用命令改名，但目前界面只在开场提供输入框。

## 新手引导（18.3）

- 一次只进行一步，做完才进下一步；每步在"它的情境出现时"打电话。实际顺序是 **1 下单 → 3 收银 → 4 看报表 → 2 上架 → 5 改价 → 6 升级**：表格里第 2 步"第 2 天货到"本来就发生在第 1 天开门、打烊之后。每步的前置步骤写在 `story.json` 的 `after` 里（2 需要 1；3 需要 1；4 需要 3；5 需要 2 和 4；6 需要 5）。表格编号保留不变。
- 各步的触发：1 开场结束后的开店前；2 有订单送到后的开店前；3 店开着的时候；4 打烊后；5 第 3 天起的开店前；6 开店前且下一阶段的营收和现金都够了。
- 完成条件只算电话打来之后做的动作（之前改过价格不算）。上架：任何一次上架都算，包括"一键上货"。看报表：玩家关掉报表面板时算看过（报表在打烊时自动弹出）。第 6 步：升级或者听完电话都算完成；如果玩家在这一步之前已经升过级，就不打这个电话。
- 引导进行中，顶栏下方显示一行"爸爸的提示：……"，做完就消失。
- 新部门讲解（和章节同时触发，排在章节后面，属于必要引导）：阶段 2 肉类（爸爸来电）和果蔬（妈妈来访）；阶段 3 海鲜（爸爸来电）；阶段 4 熟食（妈妈来访）。

## 主线章节（18.4）

- 第一章就是开场；"老顾客认出主角"放在第 2 天开门时（王阿姨）。
- 第二、三、四章在升到阶段 2、3、4 时触发。第二章有选项（"放心" / "教教我"），爸爸的回应不同。
- 结局：第四章后直接接一段尾声字幕，然后继续自由经营，没有强制结束。
- 连锁超市竞争：从阶段 3 起（和第三章同时）生效，只影响普通客流（熟食高峰客流不受影响）。曲线：口碑 0 → 客流 70%，50 → 85%，100 → 100%，中间按直线算。口碑系统还没有（M13），暂时用 `story.json` 里的占位值 50，所以阶段 3 起客流是 85%。M13 接入口碑后只需改 `GameSim.CurrentReputation()` 一处。口碑范围暂按 0–100 设计。

## 支线小故事（18.5）

- 共 8 段（列表见台词草稿）。每段只出现一次。
- 支线和心情台词共用一个冷却：距上一段至少 3 天；条件满足时每段 40% 概率出现；同一个时机最多出一段。用单独的剧情随机数，不影响顾客的随机结果（同种子仍完全可重现）。
- 触发条件可以写：时机（早上 / 开门 / 打烊等）、最早第几天、最低阶段、要先看过哪段对话、要雇有某个岗位的员工（师傅们的故事需要先雇人）。
- "节日时父母打电话问忙不忙"：节日系统（M12）还没合并，暂时改成第 10 天起某个早上的随机电话。M12 合并后可以改成节日触发。

## 学生贷款（18.6）

- 本金 $15,000，每 7 天（第 7、14、21… 天打烊时）自动还最低 $150，无利息。三个数都是占位值。
- 现金不够时有多少还多少，现金不会因为还贷变成负数；没还上的部分记为欠款，加到下一次应还的金额里。不会因此游戏失败，只触发一段主角发愁的心情台词（冷却 14 天，可被剧情提示开关关掉）。
- 玩家随时可以多还（$50 / $200 / $1,000 / 能还多少还多少），先冲抵欠款，最多还到剩余本金为止。
- 还贷算当天的支出：报表多一行"还贷款"，利润仍然等于当天现金变化（和原来的报表口径一致）。
- 还清时：主角给父母打电话报喜，并播放庆祝动画；之后不再扣款。
- 主界面右上角显示剩余贷款和"还款"按钮，点开是贷款面板（剩余、最低还款、下次还款日、欠款）。
